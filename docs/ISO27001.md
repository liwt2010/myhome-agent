## 6. 内部审计

### 6.1 频率

- 每年 ≥ 1 次完整 ISMS 审计
- 高风险控制 ≥ 2 次/年
- 新增控制实施后立即审

### 6.2 审计员

- 内审员：内部 + 培训合格
- 外审员：认证机构（BSI / SGS / TÜV）

## 7. 管理评审（每年）

- 评审内容：风险评估结果 + 事件 + 控制效果 + 改进
- 决策：资源分配 + 控制调整 + 战略
- 输出：会议纪要 + 改进计划

## 8. 认证流程

```
M-12月 启动：定义范围 + SoA
M-10月 风险评估 + 内部审计
M-8月  整改 + 文档完善
M-6月  选认证机构 + 签合同
M-3月  Stage 1 审计（文档评审）
M-2月  Stage 2 审计（现场审核）
M       颁发证书（3 年有效）
M+12月 监督审计（每年）
M+36月 重新认证
```
