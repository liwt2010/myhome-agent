# 真实世界联调流程（v2.0）

> v2.0 真实家庭试用完整流程（HARDWARE_INTEGRATION.md 之后的下一步）。
> 总时长 6-8 周。**必做**：商业化发布前。

## 1. 招募（1 周）

### 1.1 3 角色家庭画像

| 角色 | 画像 | 必测场景 |
|------|------|---------|
| **老人家庭**（≥70 岁老人 + 子女）| 5-7 口人，老大主导 | §38 老人守护 19 场景全跑 |
| **儿童家庭**（≤12 岁儿童 + 父母）| 4 口人 | §38 儿童 + 视觉 16 条 |
| **独居**（1-2 人 + 偶尔访客）| 双职工 / 自由职业 | §38 全部 + TG bot 远程 |

### 1.2 招募条件

- 自有 NAS 或愿意装 Linux 主机
- 有 ≥ 3 个智能设备（米家/涂鸦/Hue 任一）
- 愿意 2 周提供反馈 + 1 次访谈
- 知情同意书签字（隐私红线 + 数据收集范围）

### 1.3 知情同意书要点

- 数据范围：设备状态、规则触发、聊天（不含摄像头原始视频）
- 收集方式：仅本地 SQLite + 上报的聚合数据
- 退出权：随时卸载 + 删 db
- 联系：管理员 admin@myhome.local

## 2. 安装（2 天）

### 2.1 上门 / 远程安装

- 硬件清单：NAS + 摄像头 ×2 + 智能灯 ×3 + 传感器 ×2
- 装 `myhome-agent` + init + serve
- 配 .env + 摄像头 ONVIF/RTSP URL
- PWA 加桌面 + Web Push 配
- TG bot 创建 + 家庭成员 bind

### 2.2 安装清单

```
□ NAS 装 Python 3.11 + myhome-agent
□ .env 配 DEEPSEEK_API_KEY / TELEGRAM_BOT_TOKEN / KMS_PASSPHRASE
□ myhome-agent init 建表
□ 5 条 P0 规则 armed
□ 3 品牌摄像头 RTSP 测试
□ TG bot 创建并 /bind
□ PWA 加桌面
□ DPO（如果是商业版）
□ DPIA 跑一遍
□ 应急响应演练
```

### 2.3 安装时数据采集

- 安装耗时（目标：≤ 2 小时）
- 用户反馈"卡点"（什么看不懂）
- 设备接入成功率

## 3. 第 1 周：基础功能验证

### 3.1 每天检查

| 时段 | 看什么 |
|------|-------|
| 早晨 | "早安问候"触发了吗？ |
| 上班 | TG bot 是否能远程查状态 |
| 晚上 | 设备控制是否正常 |
| 睡前 | 明日提醒 + 报警记录 |

### 3.2 必测场景

- [ ] 一句话控制设备（"关客厅灯"）
- [ ] TG 远程看摄像头状态（v0.x 不支持原图）
- [ ] 老人触发 SOS（模拟）
- [ ] 儿童误操作 → 撤销窗生效
- [ ] 误报 5 次以上 → 自动暂停规则生效

## 4. 第 2 周：场景深入

### 4.1 老人守护

- 跌倒检测（模拟跌倒场景，验证姿态识别）
- 痴呆走失（出门未归，验证提醒）
- 用药提醒（设药盒时间，验证通知）
- 慢病异常（血压模拟，验证警告）

### 4.2 儿童守护

- 放学回家（GPS / 门锁事件）
- 婴儿哭（音频检测，v0.x 简化）
- 陌生人徘徊（门口摄像头）
- 离线缓存（PWA 飞行模式）

### 4.3 独居

- 自动学习作息（per-member 画像）
- 度假模式（离开 7 天）
- 应急响应（模拟漏水 + 自动关阀）

## 5. 反馈收集

### 5.1 每日反馈（3 分钟问卷）

```yaml
date: 2026-08-15
家庭: 张爷爷家
今日触发: 3 次（2 真异常 + 1 误报）
满意度: 8/10
最大问题: 老人说"听不懂"管家回复
建议: 多用语音，慢一点
```

### 5.2 每周反馈（30 分钟访谈）

- 误报率（应 < 10%）
- 真异常命中率（应 > 90%）
- 性能感知（对话延迟）
- 易用性（PWA / TG）
- 隐私感（摄像头 / 麦克风）
- 推荐意愿（0-10 NPS）

### 5.3 退出问卷（最后 1 天）

- 总体满意度（0-10）
- 是否会推荐给朋友（0-10 NPS）
- 哪些功能最有用（多选）
- 哪些功能没用（多选）
- 最大顾虑
- 期望改进

| **TG bind 率** | > 50% | ? |
| **自动学习生效**（误报率随时间下降）| 是 | ? |

### 6.2 用户分层

- 高活跃（每天 ≥ 5 次对话）
- 中活跃（每周 1-5 次）
- 低活跃（偶尔用）
- 流失（安装后 ≤ 3 次使用）

## 7. 退出与归档

### 7.1 用户退出权

- 卸载 myhome-agent
- 删除 db（GDPR §17）
- 导出个人数据（GDPR §20）

### 7.2 联调数据归档

- 反馈表 → docs/TESTING_RESULTS_<家庭>.md
- 截图 / 录屏 → docs/test_assets/
- 错误日志 → data/test_logs/

## 8. 联调后迭代

### 8.1 P0 紧急修复（7 天内）

- 任何阻塞用户的问题
- 数据丢失 / 隐私泄漏
- 安全漏洞

### 8.2 P1 重要改进（30 天内）

- 高频误报规则的 prompt 调优
- PWA 慢模式 UX 强化
- TG 群组支持补完

### 8.3 P2 体验优化（90 天内）

- 视觉 16 条规则种子按家庭画像调
- DPIA 自动化升级
- 第三方审计签约

## 9. 联调完成 = 商业化许可

联调全过的判定：

- [ ] 3 角色家庭均完成 2 周试用
- [ ] 误报率 < 10%
- [ ] NPS > 50
- [ ] 无 P0 阻塞
- [ ] P1 修复 < 3 项
- [ ] DPO 复审签字

**全过 = 贴 v2.0 production-ready 标签 = 启动商业化发布。**

## 10. 长期跟踪（商业化后）

- 紧急：违规响应（DPOIncidentResponse）
