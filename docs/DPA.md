# 数据保护协议（DPA）+ DPO 角色（v1.0 商业化前置）

> **同步状态（2026-08-07）**：本文档已纳入整体同步；与当前实现的差异以 [ARCHITECTURE.md](../ARCHITECTURE.md) 状态表和 `tests/` 为准。


> GDPR Article 37-39 强制要求：处理大规模敏感数据时设 DPO。
> myhome-agent v1.0 商业化版本（多家庭 SaaS）必须设 DPO。
> 开源家庭版（≤3 家庭）暂不强制，但建议任命家庭 DPO。

## 1. DPO 角色定义

| 维度 | DPO 责任 |
|------|---------|
| **GDPR 合规** | DPIA 监督、数据流审计、违规响应 |
| **§50 治理** | safety/care 规则上架审批、跨家庭数据迁移授权 |
| **§55 公共市场** | marketplace 模板 DPO 双审（safety 类）|
| **§61 2FA** | 强制场景表审计、Fernet 主密钥泄露应急 |
| **数据主体权利** | 被遗忘权 / 数据可携权 / 反对权 处理 |
| **跨境传输** | 国际家庭数据流评估 + DPA 协议 |
| **第三方审计** | 年度第三方审计联络 |

## 2. DPO 任命流程

### 2.1 商业版（v1.0+ SaaS）

```
1. 任命公告（公司董事会通过）
2. 联系方式公开（公共页面 + 隐私政策）
3. 独立性保障：不参与业务 KPI、不被解雇威胁
4. 专业认证：IAPP CIPP/E + CIPP/M 或等同
5. 资源保障：独立预算、专属团队
```

### 2.2 开源版（家庭 / ≤3 家庭）

- **可选**：admin 兼任 DPO（不推荐）
- **推荐**：家庭成员中独立第三方担任（如姑姑阿姨）
- **强制**：commercial use 必须有外部 DPO

## 3. DPO 协作流程

### 3.1 日常

| 频率 | 动作 |
|------|------|
| 每周 | 审查治理仪表盘（异常决策 / 配额超限）|
| 每月 | 审计 governance_decisions 抽样 |
| 每季度 | DPIA 复查（新增 capability / 数据流）|
| 每年 | 完整 GDPR 复审 + 第三方审计 |

### 3.2 事件响应

```
数据泄露 / 违规 → DPO 24h 内启动应急响应
├── 评估影响范围（household_id 列表）
├── 通知受影响主体（72h 内，GDPR Article 33）
├── 上报监管机构（CNIL / 当地 DPO）
├── 暂停违规处理流程
└── 7 天内整改 + 30 天后评估
```

### 3.3 与 §50 治理的对接

```
DPO 输入治理：
- DPIA 报告（每年）
- 数据主体投诉（立即）
- 第三方审计发现（30 天内）

DPO 输出来源：
- 季度风险评估（治理仪表盘）
- 跨家庭迁移请求（DPA 必审）
- marketplace 模板上架（DPA 双审）

冲突解决：DPO 异议 → §50 治理 reviewer 必看
```

## 4. DPO 与治理的分工

| 角色 | §50 治理 | DPO |
|------|---------|-----|
| 数据流设计 | ✓ | ✓ (DPIA) |
| 规则上架 | ✓ | ✓ (safety 双审) |
| 跨境传输 | ❌ | ✓ |
| 第三方审计 | ❌ | ✓ |
| 用户同意管理 | ✓ (consent_flags) | ✓ (审核) |
| 数据主体权利响应 | ❌ | ✓ |
| 违规响应 | 部分 | ✓ |

## 6. 治理仪表盘 DPO 视图（v1.0 计划）

```
DPO 仪表盘：
├── 实时：governance_decisions 流
├── 每日：误报率 / 反馈率 / 配额使用
├── 每周：DPIA 变更清单
├── 每月：审计报告（一键导出 PDF）
└── 应急：违规检测（自动告警）
```

## 7. 不设 DPO 的后果

| 场景 | 后果 |
|------|------|
| 商业 SaaS 不设 | 🟥 GDPR 罚款（€10M 或 2% 全球营收）|
| 开源家庭不设 | 🟡 用户信任下降 |
| 公共市场无 DPO 审 | 🟥 safety 规则失控 → 责任不清 |

## 8. 任命 DPO 的 ROI

| 投入 | 回报 |
|------|------|
| 1 DPO + 1 团队 | 合规 + 用户信任 + 商业可行性 |
| 第三方审计 €10K/年 | 避免 GDPR 罚款 €10M+ |
| DPIA 工具 + 流程 | 加快上架、降低风险 |
